# columns-media

Custom **columns** block. Purpose: media-text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: per row: image | heading + paragraphs/list + CTA link (put the image in the second cell to place it on the right).

- A short ALL-CAPS paragraph directly after the heading renders as the light-weight subtitle (e.g. "SHARED HISTORY"); sentence-case text after the heading is the description.
- Several CTA links (one per paragraph) sit side by side.
- Text color follows the section: white in `dark` sections, black elsewhere.

## Supported variations

No variations.
