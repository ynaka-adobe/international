# video-poster

Custom **video** block. Purpose: media.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell: poster picture (optional) + link to the video URL (YouTube, Vimeo or .mp4/.webm). Link text other than the URL is used as the video title for the play button aria-label and iframe title; otherwise the poster alt text is used.

## Supported variations

No variations.
