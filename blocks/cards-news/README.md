Custom **cards** block. Purpose: news-listing.

## Authoring (Document Authoring)

Single block table. Content: one row per news item: image | date paragraph + optional label paragraph (e.g. NEWS RELEASE) + title heading (e.g. h3) + LEARN MORE link; the first row is the featured card.
